> **状态**：Draft v0.1（2026-07-28）
> **作者**：Wyler
> **定位**：桌面端 · 桌宠 × 游戏 · 反差向小品

## 一、项目起源：我们怎么走到这里的

这一节记录项目的**思考过程**，不是结论。因为 Overworked 的核心价值不在功能清单，而在**为什么是这样一个东西**。理解了推理链，后面的每个设计决策才有了锚点。

### 1.1 起点：一个想做新项目的人

刚做完一个 5 万行、787 测试、109 篇教程的企业级 AI Agent 框架（Lumina）。很重，很完整，但也很累。

想做个新东西。要求：
- 结合 AI 能力（但不强求）
- 新颖，没人做过
- 桌面端也行，语言不限
- **不要那么重**，随便谁都能拿来用

### 1.2 第一轮筛选：为什么"有用的 AI 工具"全被否决

最初想了 6 个方向：照片大脑、屏幕 Agent、MCP Hub、口语陪练、求职 Agent、读书摘要。

**全部否决**。否决理由是同一个：

> 这些都是大厂会盯的"正经工具"赛道。demo 容易，但做出好用不简单，而且容易被大厂覆盖。

独立开发者的死穴是**和大厂正面竞争**。所以筛选逻辑必须是：**找大厂算不过账、怕 PR、或不屑做的事**。

### 1.3 第二轮筛选：放开 AI，找"有趣且不大"

把"必须结合 AI"这个约束去掉后，方向变成了：
- 环境音合成器
- 图片→音乐的通感玩具
- 极简较真工具（打字练习等做到极致）
- 复古桌面 OS
- 生成器系列

这些更轻更有趣，但**缺一个让人记住的记忆点**。它们是"不错的小品"，但没有"哇这个有点东西"的瞬间。

### 1.4 关键融合：桌宠 + 游戏 + 玩具

把"桌宠、游戏、玩具"三个词拼在一起后，找到了核心洞察：

> **桌宠的死穴是"养几天就腻"（没有成长）；游戏的死穴是"你不打开就不存在"。**
> **融合体的答案是：让桌宠常驻屏幕，但它的成长不来自"你专门玩它"，而来自"你正常用电脑"本身。**

你的真实行为（打字、切窗口、熬夜、挂机）= 游戏输入。你在用电脑就是在玩，**不需要额外花时间**。

### 1.5 为什么是"打工桌宠"：抽象 + 反差

"桌宠反映你的状态"这个框架下，有几种调性：

| 调性 | 设定 | 感觉 |
|------|------|------|
| 治愈向 | 它是你的伙伴，陪你工作 | 温暖但容易腻 |
| 养成向 | 它是你的镜像，你自律它变强 | 有趣但有点爹味 |
| **反差向** | **它是你的打工仔，你用电脑它就在被压榨** | **又好笑又心酸，传播力最强** |

选"反差向"的原因：

1. **反差 = 记忆点**：最可爱的像素小生物 × 最惨的社畜生活，这个错位本身就是传播素材
2. **共鸣 = 传播力**："它比我还惨"是每个打工人的本能反应，截图发群天然破百
3. **不爹味**：它不教育你"该休息了"，它只是**瘫在那里**——最高级的提醒是不提醒
4. **抽象 = 留白**：它从不直接评价你，你看着它的状态自己会想东西

### 1.6 一句话定义

> **Overworked 是一只住在屏幕角落的像素小生物。你用电脑，它就在打工。你加班它受伤，你摸鱼它瘫倒，你卷它就卷。你以为在养宠物，其实在养你自己的镜子。**

## 二、目标用户

### 2.1 核心用户画像

- **程序员 / 设计师 / 自媒体人 / 学生**——每天长时间用电脑，且经常加班
- **独居或远程办公**——屏幕前的时间很长，会感到孤独或需要陪伴
- **自嘲型人格**——会发"打工人打工魂""今天又是被 cpu 的一天"这类内容的人
- **喜欢精致小品**——对像素风、独立游戏、有审美的工具有好感

### 2.2 用户为什么留

不是因为它"有用"，是因为：

1. **情感投射**——它的状态就是你的状态，你会忍不住看它在干嘛
2. **愧疚驱动**——你养了它，它替你打工，你不自律它就惨，这种情感压力比 todo list 管用
3. **分享欲望**——它的各种惨状太好截图了，"我家的桌宠又瘫了"是社交货币
4. **养成惯性**——养了 3 周的小生物，你不忍心让它饿死/累死

## 三、核心玩法：你的行为 = 它的命运

### 3.1 核心循环

```
你正常用电脑（打字/移动鼠标/切窗口/专注/熬夜/挂机）
        ↓
Overworked 后台感知你的行为模式
        ↓
转化为小生物的"打工事件"
        ↓
它的状态实时变化（时薪/体力/心情/存款）
        ↓
它做出反应（冒泡吐槽/瘫倒/亢奋/渡劫）
        ↓
你看到反应 → 产生情绪（好笑/心酸/愧疚）→ 调整行为
```

**关键：你永远不需要"专门去操作它"。** 它的存在是反应性的，不是交互式的。

### 3.2 行为 → 状态映射

| 你的真实行为 | 小生物的状态变化 | 它的反应 |
|-------------|-----------------|---------|
| 噼里啪啦打字 2 小时 | "产能"高，时薪涨，但体力下降 | 亢奋冒汗，偶尔吐槽"这个需求好急" |
| 专注 5 分钟不切窗口 | 打赢一场"小怪"（= 番茄钟） | 掉落装备/材料，短暂庆祝 |
| 频繁切窗口、乱点 | "多线程"，效率低，混乱度上升 | 眼神涣散，头冒问号 |
| 挂机 30 分钟不动 | "带薪摸鱼"，体力恢复 | 摊在角落，偶尔翻白眼 |
| 凌晨 1-5 点还在用 | "夜班"，双倍产能但受伤 | 眼圈变黑，头顶冒"zzZ"但还在干活 |
| 连续 3 天高强度使用 | "过劳"，体力见底 | 脸色发青，可能"进医院"（强制休息 1 小时） |
| 整理窗口、关掉无关程序 | "清理工位"，心情小幅回升 | 吹口哨，擦桌子动画 |
| 完成一个大任务（检测到长时段专注结束） | "项目交付"，存款暴涨 | 蹦起来，撒花，然后立刻瘫倒 |

### 3.3 状态系统

四个核心属性，全部由行为驱动，用户**不可直接操作**：

| 属性 | 范围 | 说明 |
|------|------|------|
| **体力** | 0-100 | 打字消耗（系数 0.35），挂机/休息恢复。归零普通模式进医院/修仙模式走火入魔 |
| **时薪** | 浮动 | 你的产能决定它当前的"价值"。专注高时薪涨，摸鱼时薪掉 |
| **心情** | 0-100 | 过劳/熬夜/混乱降，完成番茄钟/大任务/摸鱼恢复。归零连续3天普通模式触发离职 |
| **存款** | 累积 | 它打工赚的钱。攒够了会"消失去旅游"几天，回来空着手 |

#### 关键数值参数

| 参数 | 值 | 说明 |
|------|------|------|
| 打字体力消耗 | `keys_per_sec × 0.35 × dt` | 连续打字约1.5分钟耗空 |
| 挂机体力恢复 | `1.5/tick` | 5秒tick恢复7.5 |
| 番茄钟门槛 | 300秒（5分钟） | 持续专注5分钟触发，原25分钟太难 |
| 番茄钟奖金 | +200存款 / 修仙+10修为 | |
| 修仙模式存款倍率 | ×1.5 | 修仙者效率更高 |
| 度假触发 | 存款≥3000 + 已升职 | **仅普通模式**，修仙模式免疫 |
| 离职触发 | 心情连续3天归零 | **仅普通模式**，修仙模式免疫 |
| 心魔积累 | 过劳+10~20 / 突破失败+15~30 | 修仙专属，高境界更多 |
| 心魔化解 | 打坐-0.5/tick / 心魔丹-25 / 冰封术-15 | |
| 过劳变异 | 每次走火入魔/进医院+1 | 黑眼圈/灰暗/裂纹视觉，突破成功-1 |

### 3.4 特殊事件

随机或条件触发的"剧情"，增加惊喜感和传播素材：

| 事件 | 触发条件 | 效果 | 截图传播价值 |
|------|---------|------|-------------|
| **离职** | 连续 3 天心情=0（仅普通模式） | 它收拾纸箱走了，3 天后以"新员工"身份回来（形态微变）。度假/离职期间显示"数值暂停"横幅 | ⭐⭐⭐⭐⭐ |
| **升职** | 存款达到阈值 | 头顶多个"主管"铭牌，但工作量更大了 | ⭐⭐⭐⭐ |
| **团建** | 周五下午 + 挂机 | 屏幕边缘出现几个像素同事，一起喝东西 | ⭐⭐⭐⭐ |
| **甲方催稿** | 你频繁切窗口 | 头顶冒"!!"，冒泡"甲方又改需求了" | ⭐⭐⭐⭐ |
| **午休** | 12:00-13:00 挂机 | 它趴桌上睡，头顶冒饭盒 | ⭐⭐⭐ |
| **发工资** | 每月 1 号 | 存款到账动画，它数钱 | ⭐⭐⭐⭐⭐ |

## 四、视觉与交互

### 4.1 视觉风格

- **像素风**（32x32 或 48x48），降低美术门槛，且契合"复古打工人"气质
- **主色调偏灰/暗**（办公室、格子间的视觉隐喻）
- **表情是灵魂**——同样的像素小人，靠 3-5 种表情切换（亢奋/疲惫/瘫倒/暴怒/开心）传递所有情绪
- 冒泡文字用**手写体或像素字体**，不要正经 UI 字体

### 4.2 交互原则

| 原则 | 说明 |
|------|------|
| **常驻但克制** | 默认待在角落，不抢焦点。绝不弹窗、绝不遮挡你的工作区 |
| **冒泡为主** | 信息通过头顶气泡传递，3 秒后自动消失，不打断你 |
| **可点击但无菜单** | 点击它只有简单反应（拍一下 → "哎！"），不要设置面板/数值面板——暴露数值就破坏了抽象 |
| **可拖动** | 你能把它拖到屏幕任意边缘，但拖到屏幕中间它会"自己走回去"（它知道自己的位置） |
| **右键菜单极简** | 只有"暂时消失 1 小时""关于""退出"三项。没有设置选项，保持纯粹 |

### 4.3 反例（绝对不做的事）

- ❌ 弹窗提醒"你已经工作 2 小时了，该休息了"——**爹味，破坏抽象**
- ❌ 显示数值面板（体力 67/100 这种）——**破坏留白，变成游戏就不是桌宠了**
- ❌ 推送通知——**桌宠的灵魂是"它在那里"，不是"它烦你"**
- ❌ 联网/云同步/账号——**本地优先，零隐私焦虑**

## 五、技术方案

### 5.1 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| **框架** | Tauri | 比 Electron 轻 10 倍，内存占用小，适合"常驻不碍事" |
| **核心语言** | Rust（行为感知 + 游戏逻辑） | 性能好，系统级 hook 友好 |
| **UI** | 内嵌 Web（HTML/Canvas） | 像素动画用 Canvas 最灵活；Tauri 原生支持 |
| **数据** | SQLite | 单文件本地存档，零配置 |
| **行为感知** | rdev / winapi / CoreGraphics | 监听键盘频率、鼠标活动、活跃窗口标题 |
| **AI（可选）** | 后期可加 LLM 生成吐槽文案 | MVP 不需要，模板足够 |

### 5.2 架构概览

```
┌─────────────────────────────────────────┐
│            Tauri 主进程（Rust）            │
│                                         │
│  ┌──────────────┐   ┌────────────────┐  │
│  │  行为感知层   │   │   游戏引擎      │  │
│  │              │   │                │  │
│  │ · 键盘频率   │──→│ · 状态机       │  │
│  │ · 鼠标活动   │   │ · 事件触发     │  │
│  │ · 窗口切换   │   │ · 数值系统     │  │
│  │ · 时间感知   │   │ · 存档         │  │
│  └──────────────┘   └───────┬────────┘  │
│                             │           │
│                     ┌───────▼────────┐  │
│                     │   渲染层        │  │
│                     │                │  │
│                     │ · Canvas 像素   │  │
│                     │ · 冒泡文字     │  │
│                     │ · 动画状态机   │  │
│                     └────────────────┘  │
└─────────────────────────────────────────┘
              │
        ┌─────▼─────┐
        │  SQLite   │  本地存档
        │  存档库    │  （行为日志 + 角色状态 + 装备）
        └───────────┘
```

### 5.3 行为感知细节

这是技术核心，需要平衡"有用"和"隐私"：

| 感知项 | 方法 | 隐私 | 用途 |
|--------|------|------|------|
| 键盘按键**频率**（不记录内容） | 全局 hook 计数 | ✅ 安全 | 判断"产能" |
| 鼠标移动距离/点击频率 | 全局 hook | ✅ 安全 | 判断"活跃度" |
| 前台窗口**标题**（可配置开关） | OS API | ⚠️ 需用户授权 | 判断"在干嘛"（可选增强） |
| 时间段 | 系统时钟 | ✅ 安全 | 判断"夜班/午休" |
| 系统空闲时长 | OS idle 检测 | ✅ 安全 | 判断"摸鱼/挂机" |

**红线：绝不记录键盘输入内容、不截屏、不上传任何数据。** 所有行为数据只存在本地，且窗口标题感知默认关闭，需用户主动开启。

### 5.4 性能要求

- 内存占用 < 80MB（Tauri 基础占用约 30-50MB，留 30MB 给游戏）
- CPU 占用 < 1%（空闲时），< 3%（动画时）
- 行为感知用低频采样（每 5 秒统计一次键盘频率，而非每次按键触发）

## 六、MVP 范围（第一版）

### 6.1 MVP 目标

**用最小的范围验证核心乐趣**：一只会感知你打字/挂机、会打工、会瘫倒的小生物。

### 6.2 MVP 功能清单

| # | 功能 | 必要性 | 说明 |
|---|------|--------|------|
| 1 | 桌面常驻（角落悬浮窗） | ✅ 必须 | Tauri 透明窗口 |
| 2 | 像素角色 + 3 种状态（干活/疲惫/瘫倒） | ✅ 必须 | 3 帧动画就够 |
| 3 | 键盘频率感知（每 5 秒统计） | ✅ 必须 | 核心输入 |
| 4 | 系统空闲检测 | ✅ 必须 | 判断挂机 |
| 5 | 体力系统（打字消耗，挂机恢复） | ✅ 必须 | 最简数值 |
| 6 | 冒泡文字（5-10 条模板） | ✅ 必须 | "需求好急""带薪摸鱼" |
| 7 | 瘫倒动画（体力归零触发） | ✅ 必须 | 第一个传播点 |
| 8 | 点击交互（拍一下会"哎！"） | ✅ 必须 | 基础交互 |
| 9 | 本地存档（重启不丢失状态） | ✅ 必须 | SQLite |
| 10 | 熬夜检测（凌晨 1-5 点） | 🟡 应该有 | 黑眼圈 + 受伤 |
| 11 | 冒泡吐槽文案随机化 | 🟡 应该有 | 增加新鲜感 |

### 6.3 MVP 明确不做

- ❌ 装备/技能树系统
- ❌ 特殊事件（离职/团建/发工资）
- ❌ 多角色选择
- ❌ LLM 生成文案
- ❌ 窗口标题感知
- ❌ 设置面板
- ❌ 联网功能

### 6.4 MVP 成功标准

> 让 3 个朋友试用一周，如果**至少 2 个人主动截图发过朋友圈/群**，说明核心反差成立，值得继续。

- ✅ **心魔系统**：inner_demon 0-100，过劳/突破失败积累，打坐/心魔丹/法术化解，影响修为/突破率/过劳

## 八、设计红线（不可妥协的原则）

这几条是项目的灵魂，任何功能迭代都不能违背：

1. **不爹味**：绝不主动提醒用户"该休息/该专注"。它只反应，不教育。
2. ~~**不暴露数值**：不显示 HP/经验条等游戏化数字。状态通过表情和动画传达。~~
   **【2026-07-29 调整】** 改为显示常驻小细条（体力/心情/存款/时薪）。
   原因：用户反馈需要直观看到状态变化（尤其验证感知/存档效果）。
   调整后仍守"反差"调性——细条用克制的小尺寸，且数值仍驱动表情动画。
3. **不抢焦点**：永远待在角落，绝不弹窗、绝不遮挡工作区。
4. **本地优先**：零账号、零联网、零隐私焦虑。
5. **反差是灵魂**：可爱 × 社畜的错位不能丢。任何让它"太正经"的设计都要否决。

### 双模式红线原则（2026-07-30 新增）

红线适用于**普通模式**。修仙模式是用户主动开启的游戏层，红线放开：

| | 普通模式（默认） | 修仙模式（用户主动开启） |
|---|---|---|
| 数值 | 克制的小细条 | 境界/修为/灵石/背包全可见 |
| 焦点 | 角落常驻不弹窗 | 独立商店窗口（用户主动打开） |
| 提示 | 只反应不教育 | 可有突破/走火入魔等主动提示 |
| UI | 极简右键菜单 | 游戏化商店 + 背包 |

用户可随时「化凡」切回普通模式。关键：修仙模式不影响普通用户体验。

## 九、修仙系统（双模式游戏层）

### 9.1 设计理念

打工是表象，修仙才是归宿。用户攒够 500 灵石后，可主动开启修仙模式，进入完整的修仙游戏层。这是 Overworked 的"第二幕"——从社畜模拟器变成修仙养成。

### 9.2 触发流程

```
普通打工 → 存款达 500 → 右键菜单「？？？」解锁
→ 购买修仙入门券（500 灵石）→ 进入修仙模式
→ 境界条 + 修为条出现 → 打工/专注积累修为
→ 修为满 100 → 买突破丹 → 尝试突破
→ 成功升境界 / 失败走火入魔 → ... → 飞升结局
```

存款首达 500 时有彩蛋提示（金光觉醒 + 冒泡），之前菜单显示「？？？」保留神秘感。

### 9.3 境界体系（7 阶）

| 境界 | 修为门槛 | 突破丹价 | 视觉效果（程序绘制） |
|---|---|---|---|
| 凡人 | - | - | 普通打工仔 |
| 练气 | 入门券 500 | 200 | 青色微光 + 3 颗气点绕体旋转 |
| 筑基 | 100% | 500 | + 蓝白灵体光罩 + 漂浮灵魂碎片 |
| 金丹 | 100% | 1000 | + 胸口金丹（脉冲+轨道粒子） |
| 元婴 | 100% | 3000 | + 头顶双层光环 + 元婴小分身 |
| 化神 | 100% | 8000 | + 全身金光 + 6 颗环绕光粒 + 脚下光台 + 悬浮 |
| 飞升 | 100% | - | 金光大柱 + 角色消失 + 通关字幕 |

突破成功率 90%→50% 递降，受**心魔值**影响（心魔越高越难突破）。可通过**境界任务加成**（+2~8%）提升，但心魔高时惩罚可达 -30%。失败 = 走火入魔（修为清零 + 体力降低 + 心魔增加 + 魔气缠身特效）。

### 9.4 修仙商店（天工阁）

独立窗口，古风金墨 UI，四个区域：

**丹药阁**：突破丹/回气丹（+50 体力）/ 续命丹（免疫一次过劳送医）/ 聚灵符（修为 ×2 一小时）

**灵兽苑（坐骑）**：5 种程序绘制坐骑，桌宠骑在上面（上移+悬浮）：

| 坐骑 | 价格 | 最低境界 | 视觉 |
|---|---|---|---|
| 飞剑 | 1000 | 练气 | 银白剑身 + 灵光拖尾 |
| 葫芦 | 2000 | 筑基 | 横版骑葫芦 + 红绳腰带 |
| 青龙 | 5000 | 金丹 | 三层龙身 + 龙须龙鳞龙爪 |
| 麒麟 | 8000 | 元婴 | 金甲鳞甲 + 鬃毛 + 双角 |
| 凤凰 | 15000 | 化神 | 分层羽翼 + 凤冠 + 长尾翎眼 |

**万法殿（法术）**：5 种全屏特效，**买一次永久解锁**，施展消耗体力 + 获得修为/时薪 + 各自心魔影响 + 坐骑共鸣×1.5：

| 法术 | 价格 | 体力消耗 | 修为+ | 时薪+ | 心魔影响 | 特效 |
|---|---|---|---|---|---|---|
| 火球术 | 300 | 10 | 5 | 3 | +5（烈焰躁动） | 30 颗火焰粒子爆裂 |
| 冰封术 | 600 | 15 | 8 | 5 | -15（冰心诀） | 5 层冰霜环 + 冰晶绽放 |
| 雷劫术 | 1200 | 20 | 12 | 8 | -10（以雷炼心） | 3 道闪电劈下 + 电弧 |
| 万剑诀 | 3000 | 30 | 18 | 12 | -5（剑心通明） | 36 把光剑天降 |
| 天地同寿 | 8000 | 45 | 25 | 18 | -20（大道至简） | 五色光柱冲天 + 全屏绽放 |

**坐骑共鸣**：骑坐骑时施展法术，修为收益 ×1.5（人骑合一，灵力倍增）

**悬赏榜（任务）**：
- **日常任务**：随机抽 3 个（打工攒灵石/专注修炼/施展法术/静心打坐，持久化），完成后领灵石+修为奖励
- **境界剧情任务**：6 境界 23 场景，分支路径+隐藏选项（心魔/坐骑触发）+心魔联动选项（斩心魔可降低心魔值）

**心魔系统**：
- 心魔值 0-100，过劳走火入魔/突破失败时积累（高境界更多）
- 化解：打坐挂机 -0.5/tick、心魔丹 -25（每境界限3个）、冰封术 -15
- 影响：心魔 30+修为×0.8/突破-10%，60+修为×0.6/突破-20%/跳过续命丹，80+修为×0.4/突破-30%

**功德碑（成就）**：12 项成就（境界/坐骑/法术/心魔/变异/灵石），解锁给灵石奖励

**今日简报**：今日按键/打工时长/摸鱼时长/连续天数/境界/心魔体力

### 9.5 化凡与重入

- 随时可「化凡」切回普通模式，保留境界进度
- 重入修仙免费（不扣 500），恢复原境界
- 已飞升的存档启动时桌宠自动隐藏，托盘菜单提供「复活」
