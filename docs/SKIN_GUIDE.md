# Overworked 皮肤制作指南（美术向）

> 本文档面向美术同学。看完就能独立制作一套完整皮肤，无需了解代码。

---

## 一、30 秒速览

你要做的：**11 个文件夹，每个文件夹放几张 PNG**，按命名规则放进去就生效。

```
skins/你的皮肤名/
├── idle/       1.png 2.png 3.png     ← 待机动画
├── working/    1.png 2.png ...       ← 干活动画
├── ...
```

放好后，用户右键桌宠 →「换皮肤」→ 选你的皮肤名，立刻生效。

---

## 二、技术规格（硬性要求）

| 项目 | 要求 | 说明 |
|---|---|---|
| **单帧尺寸** | **32 × 32 像素** | 固定。所有帧必须同尺寸 |
| **格式** | **PNG** | 必须。支持透明 |
| **背景** | **必须透明** | 不能有任何背景色，否则会显示一块色斑 |
| **文件命名** | `1.png` `2.png` `3.png` ... | 从 1 开始连续编号，不能跳号 |
| **文件夹命名** | 见下方动作清单（小写） | 必须完全匹配 |

> ⚠️ 帧尺寸必须是 **32×32**。代码会把它放大 3 倍显示（→ 96×96），所以 32×32 是原生分辨率，放大后保持像素感。不要画成 96×96 或其他尺寸。

## 三、11 个动作清单

每个动作 = 一个文件夹。每个文件夹内放该动作的序列帧。

### 动作分类

| 分类 | 动作 | 触发场景 | 推荐帧数 | 循环方式 |
|---|---|---|---|---|
| **状态** | `idle` | 默认/挂机待机 | 3-4 帧 | 循环 |
| **状态** | `working` | 打字中（干活） | 3-4 帧 | 循环 |
| **状态** | `tired` | 体力下降（累） | 3 帧 | 循环 |
| **状态** | `exhausted` | 体力归零（瘫倒） | 2-3 帧 | 循环 |
| **状态** | `overworked` | 连续过劳（崩溃边缘） | 3 帧 | 循环 |
| **状态** | `nightshift` | 凌晨1-5点（夜班） | 3 帧 | 循环 |
| **状态** | `happy` | 番茄钟完成/任务交付（庆祝） | 3 帧 | 循环 |
| **交互** | `poke` | 被戳（按住期间循环播放） | 2 帧 | 按住循环 |
| **交互** | `drag` | 被拖动（挣扎姿态） | 2 帧 | 拖动循环 |
| **生动** | `walk` | 随机散步（沿屏幕底边走） | 4 帧 | 播放几轮 |
| **生动** | `jump` | 随机跳一下 | 2 帧 | 播 2 轮 |

### 各动作的帧间动画含义

帧序号代表动画时间轴。以下是每个动作各帧应该画什么：

#### `idle`（待机）— 3 帧
- 第 1 帧：站立，正常姿态
- 第 2 帧：身体微下移 1px（呼吸下沉）
- 第 3 帧：闭眼（眨眼），身体保持下沉

#### `working`（干活）— 4 帧
- 第 1-2 帧：身体轻微上下（打字节奏）
- 第 3-4 帧：重复（或手部抬起像敲键盘）

#### `tired`（累）— 3 帧
- 第 1-2 帧：头微低/前倾，八字眉，下垂嘴
- 第 3 帧：闭眼，更疲惫

#### `exhausted`（瘫倒）— 2 帧
- 第 1 帧：完全瘫倒（趴桌上/躺平），X 眼
- 第 2 帧：身体更低（彻底放弃）

#### `overworked`（崩溃边缘）— 3 帧
- 第 1 帧：身体左歪 1px
- 第 2 帧：身体右歪 1px（颤抖感）
- 第 3 帧：回正 + 冒汗

#### `nightshift`（夜班）— 3 帧
- 第 1-2 帧：打盹姿态（头歪），黑眼圈，头顶 zZ
- 第 3 帧：闭眼

#### `happy`（庆祝）— 3 帧
- 第 1-3 帧：蹦跳（身体上下），^眼，笑嘴，抬手庆祝

#### `poke`（被戳）— 2 帧
- 第 1 帧：惊跳（上扬眉，张嘴，身体上移）
- 第 2 帧：落回正常

#### `drag`（被拖动）— 2 帧
- 第 1 帧：身体左歪（挣扎）
- 第 2 帧：身体右歪（挣扎）

#### `walk`（走路）— 4 帧
- **⚠️ 特殊：只画朝右方向！朝左由系统自动镜像。**
- 第 1 帧：迈左脚
- 第 2 帧：双脚并拢，身体微上
- 第 3 帧：迈右脚
- 第 4 帧：双脚并拢，身体微上
- 角色必须是**侧面视角**（脸朝右）

#### `jump`（跳）— 2 帧
- 第 1 帧：跳起（身体上移 4px，表情开心）
- 第 2 帧：落地（回正常）

---

## 四、帧数灵活说明

- 推荐帧数只是建议。**画多画少都能用**——代码按实际文件数播放。
- 如果某动作只画 1 帧：该动作变成静态图（不循环动画）。
- 如果某动作**不画（文件夹不存在）**：系统自动用 `idle` 替代（fallback）。
- 所以最简皮肤只需 `idle` 一个文件夹（1 帧），其他全部 fallback。但体验会很单调。

## 五、角色设计建议（审美向）

### 核心原则：萌惨反差

Overworked 的灵魂是**可爱 × 社畜惨状**的错位。角色设计要同时满足：
- **萌**：大头、圆脸、大眼（chibi 比例，头身比约 1:1）
- **惨**：八字眉、下垂嘴、黑眼圈、汗、驼背

### 32×32 下的设计要点

1. **剪影优先**：把图涂成纯黑，还能认出在干嘛吗？每个状态的轮廓要不同
2. **神态 = 眉毛 + 嘴**：32×32 下情绪主要由眉毛角度 + 嘴形传达，眼睛辅助
3. **深色轮廓线**：1px 描边让角色在透明背景上清晰（非常重要）
4. **色阶 ramp**：每个颜色配亮/中/暗三级（亮色在上、暗色在右下），增加体积感
5. **一个强调色**：领带/工牌等用一个亮色跳出来，是视觉焦点

### 各状态的表情速查

| 状态 | 眉毛 | 眼睛 | 嘴 | 其他 |
|---|---|---|---|---|
| idle | 无/平 | 圆眼（带眼神光） | 中性直线 | - |
| working | 平 | 圆眼 | 中性 | - |
| tired | 八字眉（外端下垂）| 半睁横线 | 下垂 ⌒ | 汗滴 |
| exhausted | 无 | X 眼 | 张开 O | 驼背/趴桌 |
| overworked | 八字眉 | 半睁 | 抖动 | 黑眼圈 + 汗 + 颤抖 |
| nightshift | 八字眉 | 半睁/闭 | 张开/中性 | 黑眼圈 + zZ |
| happy | 上扬 ^ | ^ 眼 | 笑容 ⌣ | 腮红 + 抬手 |
| poke | 上扬 | 圆眼/惊讶 | 张开 O | - |
| drag | 怒眉 | 圆眼 | 张开 | 身体歪斜 |
| jump | 上扬 | ^ 眼 | 笑容 | - |

### 配色建议

- **主色（60%）**：衬衫，去饱和的灰蓝/灰褐（不要纯灰，要带色温）
- **辅色（30%）**：皮肤 + 头发
- **强调色（10%）**：领带/配饰，亮色（橙/红/亮蓝），要跳出来
- **轮廓色**：比所有色都深（接近黑但不纯黑），1px 描边

**避免**：纯灰（太死）、高饱和原色（太刺）、每状态换主色（状态靠表情传达，不靠换衣服）。

## 六、交付检查清单

做完一套皮肤后，对照检查：

- [ ] 11 个文件夹都建了（或至少有 idle）
- [ ] 每个文件夹里的 PNG 是 `1.png 2.png ...` 连续编号
- [ ] 每张 PNG 是 32×32 像素
- [ ] 背景是透明的（不是白色/黑色）
- [ ] walk 是侧面朝右（系统会自动镜像左走）
- [ ] 每个状态的剪影能区分（涂黑看轮廓）
- [ ] 角色在帧内大致居中
- [ ] 文件夹名全小写、拼写正确

---

## 七、如何测试你的皮肤

1. 把你的皮肤文件夹放进 `skins/` 目录（和 `default` 平级）
   ```
   skins/
   ├── default/      ← 系统自带
   └── 你的皮肤名/   ← 你做的
   ```
2. 启动应用
3. 右键桌宠 →「换皮肤」→ 选你的皮肤名
4. 用「动作预览」逐个检查每个动作的播放效果
