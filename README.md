# Overworked

> 一只住在屏幕角落的像素打工仔。你用电脑，它就在打工。

## 这是什么

Overworked 是一个桌面桌宠应用。它常驻在你的屏幕角落，感知你的电脑使用行为（打字、挂机、熬夜），并用一个像素小生物的"打工状态"来反映。

你加班它受伤，你摸鱼它瘫倒，你卷它就卷。你以为在养宠物，其实在养你自己的镜子。

## 状态

🚧 规划中 — 参见 [PRD](docs/PRD.md)

## 技术栈

- Tauri（桌面端，轻量）
- Rust（行为感知 + 游戏逻辑）
- Canvas（像素动画）
- SQLite（本地存档）

## 原则

- 不爹味：它只反应，不教育
- 不暴露数值：状态靠表情传达，不显示 HP 条
- 本地优先：零账号、零联网、零隐私焦虑
