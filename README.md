# 🐱 Overworked — 打工桌宠

> 一只住在屏幕角落的像素打工仔。你用电脑，它就在打工。
> 你加班它受伤，你摸鱼它瘫倒，你卷它就卷。你以为在养宠物，其实在养你自己的镜子。
> 攒够灵石，它还能踏上修仙之路——打工是表象，修仙才是归宿。

---

## 📥 安装

### Windows

1. 下载最新的 `Overworked_0.1.0_x64-setup.exe`（[Releases](../../releases)）
2. 双击安装（安装程序会自动关闭旧版本）
3. 启动后桌宠出现在屏幕右下角

> 首次安装后 Windows 可能弹出 SmartScreen 提示（因为没有代码签名证书），点击「更多信息」→「仍要运行」即可。

### 从源码构建

```bash
git clone https://gitee.com/wyler_admin/overworked.git
cd overworked
npm install
npm run tauri build
# 产物：src-tauri/target/release/bundle/nsis/Overworked_0.1.0_x64-setup.exe
```

### macOS / Linux

目前仅支持 Windows。macOS 适配代码框架已就绪，欢迎社区贡献（见 [贡献指南](#-贡献)）。

## 🎮 玩法

### 普通模式（默认）

桌宠待在屏幕角落，**感知你的电脑使用行为**来变化状态：

| 你的行为 | 桌宠的反应 |
|---------|-----------|
| 噼里啪啦打字 | 认真打工，体力下降，时薪上涨 |
| 挂机不动 | 带薪摸鱼，体力恢复，瘫在角落 |
| 凌晨还在用 | 熬夜加班，黑眼圈+灵魂出窍 |
| 连续高强度 | 过劳送医 / 加班变异（黑眼圈+裂纹） |
| 专注5分钟 | 番茄钟完成！项目交付奖金到账 |

**不需要专门操作它**——它只反应，不打扰，不弹窗，不教育。

**交互**：
- **点击**：戳一下会有反应
- **拖动**：拖到屏幕任意位置（拖到空中松开会掉落+弹跳）
- **右键**：菜单（商店/换皮肤/打工日报/投喂咖啡/暂时消失/打开皮肤目录）
- **Shift+右键**：调试模式（动作预览/事件触发/修仙调试）

### 修仙模式（彩蛋）

普通模式下**存款攒够 500** 后，右键菜单的「？？？」解锁为「商店 / 修仙」。开启后进入完整的修仙游戏层：

```
凡人 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 飞升
```

- **7 境界**：每境界程序绘制不同的光环效果（青气/灵体/金丹/光环/金光悬浮）
- **突破**：修为满 100 买突破丹，成功率受心魔影响
- **心魔系统**：过劳/突破失败积累心魔，打坐/心魔丹/法术化解。心魔越高→修为越慢/突破越难/过劳越危险
- **境界剧情**：6 境界 23 场景，分支选择+隐藏选项+心魔联动
- **5 种坐骑**：飞剑/葫芦/青龙/麒麟/凤凰（程序绘制带完整动画）
- **5 种法术**：永久解锁，施展消耗体力+获得修为，每种法术有独特的心魔影响
- **12 项成就**：功德碑记录你的修仙历程
- **飞升结局**：最高境界金光大柱+通关字幕

## 🎨 自定义皮肤

皮肤采用**约定大于配置**——按文件夹命名规则放图即可：

```
skins/
└── 你的皮肤名/
    ├── idle/
    │   ├── 1.png    ← 序列帧，背景透明
    │   └── 2.png
    ├── working/
    │   └── ...
    └── ...（18 个普通动作 + 21 个修仙动作，缺的自动 fallback）
```

**快速开始**：右键桌宠 →「打开皮肤目录」→ 把你的皮肤文件夹放进去 → 右键 →「换皮肤」

详细规范见 [皮肤制作指南](docs/SKIN_GUIDE.md)。

## 🏗️ 技术栈

| 组件 | 选型 | 用途 |
|------|------|------|
| 框架 | Tauri 2 | 轻量桌面端（比 Electron 小 10 倍） |
| 后端 | Rust | 行为感知 + 游戏逻辑 + 存档 |
| 前端 | HTML/Canvas | 像素动画 + 粒子特效 |
| 存档 | SQLite | 本地单文件（44 字段事件追踪） |
| 感知 | rdev | 全局键盘/鼠标 hook（**只记频率不记内容**） |

**三窗口架构**：
- `main`（160×260）：透明置顶桌宠本体 + 境界光环 + 坐骑
- `fx-overlay`（全屏）：透明点击穿透，粒子/法术特效
- `shop`（420×720）：修仙商店独立窗口

**隐私**：零账号、零联网、零隐私焦虑。感知层只统计按键频率，不记录按键内容、不截屏、不上传。

## 📁 项目结构

```
overworked/
├── src-tauri/src/          Rust 后端
│   ├── sensing/            行为感知（Windows/macOS/Stub）
│   ├── engine/             游戏引擎（状态机/事件/存档/修仙/心魔）
│   ├── rendering_bridge/   数值→表情映射
│   └── skin.rs             皮肤扫描 + base64
├── src/                    前端
│   ├── main.js             桌宠渲染 + 坐骑/光环/变异绘制
│   ├── fx.js               全屏特效（粒子/法术/突破/飞升）
│   ├── shop.js             修仙商店（丹药/坐骑/法术/任务/成就/简报）
│   └── styles.css          样式
├── skins/default/          默认皮肤（39 动作 × N 帧）
├── docs/                   文档（PRD + 皮肤指南）
└── scripts/                工具脚本
```

## 🤝 贡献

欢迎贡献！以下是一些方向：

### macOS 适配 🍎

代码框架已就绪（`sensing/mod.rs` 的 `cfg(target_os = "macos")` 切换 + `macos.rs` CGEventTap 骨架），需要 Mac 环境的贡献者完成：
- 编译验证 + 补充空闲检测（CoreGraphics）
- 辅助功能权限弹窗处理
- 透明窗口 macos-private-api
- 签名公证

### 自定义皮肤 🎨

按 [皮肤制作指南](docs/SKIN_GUIDE.md) 制作皮肤，PR 提交到 `skins/` 目录。

### 数值平衡 ⚖️

心魔积累速度、突破成功率、灵石获取节奏等需要实机测试后微调。欢迎反馈体感。

### Bug 反馈 🐛

发现 bug 请提 Issue，附上：操作系统版本、复现步骤、预期 vs 实际行为。
