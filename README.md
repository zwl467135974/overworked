# Overworked

> 一只住在屏幕角落的像素打工仔。你用电脑，它就在打工。
> 你加班它受伤，你摸鱼它瘫倒，你卷它就卷。你以为在养宠物，其实在养你自己的镜子。
> 攒够灵石，它还能踏上修仙之路——打工是表象，修仙才是归宿。

## 状态

🚧 开发中 — v0.1.0

## 功能

### 普通模式（守设计红线）

- **行为感知**：感知你的打字频率、挂机时长、熬夜时段
- **状态映射**：体力/心情/存款/时薪四属性，打字消耗挂机恢复
- **18 种动作**：idle/working/tired/exhausted/overworked/nightshift/happy + poke/drag/walk/jump + leave/return/promoted/teambuilding/lunchnap/payday/vacation
- **皮肤系统**：按命名规则放图即可换皮肤，支持任意尺寸/风格（39 动作：18 普通 + 21 修仙）
- **特殊事件**：番茄钟(5分钟)/过劳送医/离职回归/升职/度假/团建/午休/发工资
- **状态横幅**：度假/离职/住院时显示"数值暂停"提示
- **趣味玩法**：Boss 来了/投喂咖啡/每日语录/成就系统
- **打字特效**：全屏粒子爆裂（发光+冲击波+震屏）
- **桌面物理**：拖到空中掉落+弹跳+沿底边走
- **本地存档**：离线睡觉恢复+位置记忆+统计
- **系统托盘**：不占任务栏但随时可找到

### 修仙模式（用户主动开启，放开红线）

攒够 500 灵石后，右键菜单的「？？？」解锁为「商店 / 修仙」，开启双模式修仙游戏层：

- **7 境界体系**：凡人→练气→筑基→金丹→元婴→化神→飞升
- **境界光环**：每境界程序化绘制视觉差异（青气/灵体/金丹/光环/金光+悬浮）
- **修为积累**：打工/专注/番茄钟交付积累修为，聚灵符 ×2
- **突破机制**：修为满 100 买突破丹尝试突破，成功率 90%→50% 递降，可通过任务加成+心魔丹提升
- **走火入魔**：突破失败惩罚（修为清零+体力降到30+魔气缠身特效）
- **飞升结局**：最高境界金光大柱+角色消失+通关字幕
- **化凡/重入**：可随时切回普通模式（化凡），重入免费保留境界
- **21 种修仙动作**：与 18 普通动作 1:1 对应（道袍换色+修仙特效），修仙模式下零漏洞
- **事件隔离**：度假/离职仅在普通模式触发，修仙模式免疫打工事件干扰

### 修仙商店（天工阁）

独立窗口，古风金墨 UI，分五个区域：

- **丹药阁**：突破丹/回气丹/续命丹/聚灵符/心魔丹（每境界限购3个，+5%突破率）
- **灵兽苑（坐骑）**：5 种程序化绘制坐骑（带完整动画），买了装备后桌宠骑在上面
  - 飞剑（银白剑身+灵光拖尾）/ 葫芦（横版骑葫芦+红绳腰带）/ 青龙（三层龙身+龙须龙鳞龙爪）/ 麒麟（金甲鳞甲+鬃毛+双角）/ 凤凰（分层羽翼+凤冠+长尾翎眼）
- **万法殿（法术）**：5 种全屏法术特效，**买一次永久解锁**，施展消耗体力+获得修为/时薪（施法如工作）
  - 火球术（爆裂，-10体力）/ 冰封术（冰晶绽放，-15）/ 雷劫术（闪电劈下，-20）/ 万剑诀（光剑天降，-30）/ 天地同寿（五色光柱冲天，-45）
- **悬赏榜（任务）**：日常任务（随机3个，给灵石/修为）+ 境界剧情任务（一次性，给突破加成）
- **储物袋**：道具库存

### 调试模式

Shift + 右键打开调试菜单：动作预览/事件触发/修仙调试（设境界/装备坐骑/施展法术/触发特效/复活）

## 技术栈

- Tauri 2（多窗口：main 桌宠 + fx-overlay 全屏特效 + shop 商店）
- Rust（行为感知 + 游戏逻辑 + 存档）
- Canvas（动画渲染 + 粒子特效 + 坐骑/境界光环程序绘制）
- SQLite（本地存档，32 字段事件追踪）
- rdev（全局键盘/鼠标感知，**只记频率不记内容**）

## 原则

- 不爹味：它只反应，不教育
- 本地优先：零账号、零联网、零隐私焦虑
- 反差是灵魂：可爱 × 社畜的错位
- **双模式红线**：普通模式守全部红线；修仙模式（用户主动开启）放开——可以有数值面板、商店窗口、游戏化 UI

## 快速开始

```bash
npm install
npm run tauri dev

# 打包
npm run tauri build
# 产物：src-tauri/target/release/bundle/nsis/Overworked_0.1.0_x64-setup.exe

# 生成默认皮肤占位图
node scripts/generate-skin.cjs
```
